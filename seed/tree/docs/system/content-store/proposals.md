# Proposals

## Proposals

- This topic is a link since `BO_0207_016`. What it described — the shell's own proposal tables and items — retired with the shell's stores; staging and answering a group of changes is the core's now.
- A proposal is a CCGW proposal group: the shell stages through the bridge's `stage` verb, reads a group's touched set and its overlay from CCGW, and answers it per member through `accept` and `reject` (`ccgw.md`, `ui-kernel.md`, `BO_0207_001`, `BO_0207_012`). [Proposed Changes](../documents/proposed-changes.md) carries what the editor does with one.
- The shell keeps no database, no bucket key and no gateway of its own (`ui-shell.md`, `BO_0207`); the history of the retired implementation stays in this topic's earlier revisions.
