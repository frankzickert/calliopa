# Relations

## Purpose

- This document is the entry point of `relations`, the extension that holds what a person says about how two blocks bear on each other: the reason-bearing `relation` between them, and the reads that answer it back. Everything here is a plain query over what people wrote — no run, no inference, no cost.
- It holds the relation because a reason-bearing relation between two blocks is predictable on its own: declared by a person or proposed by a run, and read as a plain query (`calliopa-bootstrap`'s `BO_0288`, user decision 2026-09-23).
- It is `bundled` and active on a fresh install, so relations behave the same on every install. It costs an install that never uses them nothing: a document with no relations draws none.
- It depends on `documents`, whose `text` blocks its relations anchor on and whose editor draws what it proposes, and on `ui.shell`, whose frame it contributes into.
- Its change documents carry the prefix `RL`.

## What This Extension Holds

* A relation anchors a block. The unit is the block because any block says something. User decision, 2026-09-23.
* A relation is a node carrying its kind, its reason in the reader's or the run's words, its origin and its state, joined to its source and target blocks by `source` and `target` edges. The reason is what makes propagation precise; a bare edge is too coarse to carry consequence.
* A person's declared relation is truth, written the way every human content write is. A run only ever proposes one, answered where every proposal is answered. User decision, 2026-09-13 (`BO_0244`), restated 2026-09-23 — and the reason this extension exists, since no surface has ever offered the declaration and every relation an instance holds was proposed by a run.
* `relation.state` is `declared`, `orphaned` or `retired`. `exercised` and `needsReview` were refinement's and nothing here can set or explain them. User decision, 2026-09-23.
* A block that has relations carries a neutral mark while reading, saying only that relations stand on it and that focusing it reads them. It draws no kind, origin or state, so material rule 13 holds. User decision, 2026-09-23.
* A root takes no phase. The phase and its three values, the consequences read, *Establish…*, the `policy` and `acceptedBy` behind them, and the depth surface are removed with refinement (`calliopa-bootstrap`'s `BO_0324`). User decision, 2026-10-01 (`BO_0324_Q5`).
