# Relations

## Purpose

- This document is the entry point of `relations`, the extension that holds what a person says about how two blocks bear on each other: the reason-bearing `relation` between them, the phase a root takes, and the surfaces that read both back. Everything here is a plain query over what people wrote — no run, no inference, no cost — which is the line it was split on.
- It exists because refinement did too much to be predictable (`calliopa-bootstrap`'s `BO_0288`, user decision 2026-09-23). `calliopa-refine` held the vocabulary, the judgements, the derived blocks, the gestures, the ambient marks and the surfaces all at once, and turning it on changed what every block showed. What is predictable moved here and ships; what is a model's opinion stayed there and does not.
- It is `bundled` and active on a fresh install, so relations behave the same on every install. It costs an install that never uses them nothing: depth is invisible while reading and draws only the categories that hold material, so a document with no relations draws none.
- It depends on `documents`, whose `text` blocks its relations anchor on and whose editor draws what it proposes, and on `ui.shell`, whose frame it contributes into. It renders nothing yet: the manifest names no entrypoint until `BO_0288_019` and `BO_0288_020` give it a surface, the shape `test` already stands in.
- Its change documents carry the prefix `RL`.

## What This Extension Holds

* A relation anchors a block, not a claim. The unit is the block because any block says something, and a claim only ever existed where refinement had been. User decision, 2026-09-23.
* A relation is a node carrying its kind, its reason in the reader's or the run's words, its origin and its state, joined to its source and target blocks by `source` and `target` edges. The reason is what makes propagation precise; a bare edge is too coarse to carry consequence.
* A person's declared relation is truth, written the way every human content write is. A run only ever proposes one, answered where every proposal is answered. User decision, 2026-09-13 (`BO_0244`), restated 2026-09-23 — and the reason this extension exists, since no surface has ever offered the declaration and every relation an instance holds was proposed by a run.
* `relation.state` is `declared`, `orphaned` or `retired`. `exercised` and `needsReview` were refinement's and nothing here can set or explain them. User decision, 2026-09-23.
* A block that has relations carries a neutral mark while reading, saying only that relations stand on it and that focusing it reads them. It draws no kind, origin or state, so material rule 13 holds. User decision, 2026-09-23.
* The root's phase — proposed, accepted, superseded — is this extension's, with the consequences read behind it, because *what would change if I accept this* is a relation traversal. The drift report that needs judgements stays with `calliopa-refine`. User decision, 2026-09-23.
